# What is the Meteor Guide?

The Meteor Guide is a collection of articles that outline **best practices, patterns, and architecture choices** for building applications with Meteor. It’s designed to help you make the most of Meteor’s features while keeping your codebase clean, scalable, and maintainable.

The Guide covers concepts that go beyond Meteor itself—many of its recommendations apply to any modern, interactive web or mobile application. From data management and methods to front-end integration with [React](https://react.dev/), [Vue](https://vuejs.org/), [Svelte](https://svelte.dev/), [Blaze](https://blazejs.org/), or [Solid](https://www.solidjs.com/), the Meteor Guide helps you understand how to structure your apps the right way.

You’re not required to follow the Guide to build with Meteor—but it reflects what has worked best across the community and production-grade projects. By adopting these practices, you can avoid common pitfalls and write applications that evolve smoothly as Meteor grows.

For specific API documentation, visit the [API](../api/README.md) section.  
To explore and contribute to the broader ecosystem, check out the [Meteor GitHub repository](https://github.com/meteor/meteor) or browse community packages on [Atmosphere](https://atmospherejs.com/).
