## v3.5.1-beta.0, 2026-07-23

### Highlights

#### Rspack

- Support `Npm` and `Assets` in server code when running the app with the Rspack dev server, [PR#14608](https://github.com/meteor/meteor/pull/14608)
- Reliably free the Rspack dev server port when you stop the app, so restarts no longer fail with a port-in-use error, [PR#14406](https://github.com/meteor/meteor/pull/14406)
- Reduce and monitor memory usage of the Rspack build, [PR#14464](https://github.com/meteor/meteor/pull/14464)
- Clear a `elliptic` security-audit warning coming from the Rspack build toolchain, [PR#14584](https://github.com/meteor/meteor/pull/14584)
- Fix Rspack builds failing on Windows paths that contain spaces, [PR#14474](https://github.com/meteor/meteor/pull/14474)

#### Change Streams & MongoDB

- Recover automatically instead of getting stuck in a restart loop when MongoDB reports the change-stream history was lost, [PR#14607](https://github.com/meteor/meteor/pull/14607)
- Fix method calls (such as login) occasionally hanging when using change streams under load, [PR#14564](https://github.com/meteor/meteor/pull/14564)
- Fix a server crash that could happen when comparing operation times with change streams, [PR#14609](https://github.com/meteor/meteor/pull/14609)
- Fix reactivity glitches by keeping each connection's change-stream state isolated, [PR#14602](https://github.com/meteor/meteor/pull/14602)
- Fix a server crash when a subscription stops, [PR#14540](https://github.com/meteor/meteor/pull/14540)
- Fall back gracefully when a subscription uses a projection that change streams don't support, instead of erroring, [PR#14518](https://github.com/meteor/meteor/pull/14518)
- Fix a server crash caused by certain admin-database operations appearing in the oplog, [PR#14519](https://github.com/meteor/meteor/pull/14519)
- Show a clearer error when connecting to a MongoDB replica set that hasn't been initialized, [PR#14520](https://github.com/meteor/meteor/pull/14520)
- Fix TypeScript types for the bundled MongoDB driver so editor autocompletion works, [PR#14422](https://github.com/meteor/meteor/pull/14422)

#### More reliable reconnections

- Deliver messages sent while briefly disconnected once the connection is back, instead of dropping them, [PR#14542](https://github.com/meteor/meteor/pull/14542)
- Stop brief network blips from causing spurious disconnect events and reconnect errors in the browser, [PR#14534](https://github.com/meteor/meteor/pull/14534), [PR#14532](https://github.com/meteor/meteor/pull/14532)
- Fix a server-side memory leak from connections that were closed, [PR#14538](https://github.com/meteor/meteor/pull/14538)
- Run subscription stop callbacks reliably when a subscription is stopped, [PR#14544](https://github.com/meteor/meteor/pull/14544)
- Avoid errors when the same subscription or observer is stopped more than once, [PR#14536](https://github.com/meteor/meteor/pull/14536)
- Ignore malformed DDP messages instead of dropping the whole connection, [PR#14530](https://github.com/meteor/meteor/pull/14530)
- Fix edge cases in session resumption so short disconnects reconnect cleanly, [PR#14528](https://github.com/meteor/meteor/pull/14528)
- Fix a batching issue that could leave client data momentarily inconsistent after an update, [PR#14526](https://github.com/meteor/meteor/pull/14526)

#### Improvements

- Read the current method's name inside a server method via `this.name`, [PR#14478](https://github.com/meteor/meteor/pull/14478)
- Add an opt-in `packages.webapp.skipCompressionWithContentLength` setting to leave responses that already declare a `Content-Length` uncompressed, [PR#14588](https://github.com/meteor/meteor/pull/14588)
- Update password hashing dependencies in `accounts-password` (`bcrypt` 6.0.0, `argon2` 0.44.0), [PR#14407](https://github.com/meteor/meteor/pull/14407)
- Produce smaller, faster server output by compiling server code to es2022 on modern Node, [PR#14369](https://github.com/meteor/meteor/pull/14369)
- Remove the Node.js deprecation warnings (`url.parse`, `util._extend`) that showed up during builds, [PR#14558](https://github.com/meteor/meteor/pull/14558)
- Update the bundled build-tool dependencies, [PR#13814](https://github.com/meteor/meteor/pull/13814)

#### Fixes

- Fix the dev server hanging on restart when the app ignores SIGTERM — it is now force-killed, [PR#14516](https://github.com/meteor/meteor/pull/14516)
- Deliver runtime updates to `Meteor.settings.public` to clients that connect after the change, [PR#14515](https://github.com/meteor/meteor/pull/14515)
- Fix a server crash from a malformed request URL, [PR#14598](https://github.com/meteor/meteor/pull/14598)
- Avoid spurious connection timeouts when using a non-sockjs DDP transport, [PR#14546](https://github.com/meteor/meteor/pull/14546)
- Fix a Node.js "max listeners exceeded" warning on server shutdown, [PR#14259](https://github.com/meteor/meteor/pull/14259)
- Fix the dev proxy not cleaning up websocket connections, [PR#14386](https://github.com/meteor/meteor/pull/14386)
- Fix the file watcher occasionally failing on `EINTR` signals, [PR#14450](https://github.com/meteor/meteor/pull/14450)
- Fix package assets added with `api.addAssets` being mistakenly treated as compilable source files, [PR#14566](https://github.com/meteor/meteor/pull/14566)
- Show lazy compilation errors instead of silently swallowing them, [PR#14491](https://github.com/meteor/meteor/pull/14491)
- Fix binding the server to an IPv6 host producing a malformed URL, [PR#14553](https://github.com/meteor/meteor/pull/14553)
- Fix `mongo` and `webapp` TypeScript definitions so they work with modern TypeScript, [PR#14556](https://github.com/meteor/meteor/pull/14556)
- Fix building apps that use symlinked packages in a monorepo, [PR#14442](https://github.com/meteor/meteor/pull/14442)
- Enable the modern Cordova configuration by default when you haven't set an override, [PR#14411](https://github.com/meteor/meteor/pull/14411)
- Fix an internal build-tool state bug in `tools-core`, [PR#14573](https://github.com/meteor/meteor/pull/14573)
