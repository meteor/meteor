## v3.7.0, 2026-XX-XX

### Highlights

#### Features

- Accounts emails ship with an HTML version: the site name or a logo on top, a greeting by name, a button in the accent color, the link in clear and the lifetime of the link; `Accounts.emailTemplates.layout` renders the same frame around custom content, with `logoUrl` and `accentColor` as the new settings. Apps that customized only the `text` of an email keep sending text-only emails, [PR#14986](https://github.com/meteor/meteor/pull/14986).

#### Improvements
N/A

#### Fixes

- `Accounts.emailTemplates.siteName` is set by `accounts-base`, so apps using `accounts-passwordless` without `accounts-password` no longer get `undefined` in their email subjects.

#### Breaking Changes
N/A

#### Internal API changes

- `Accounts._defaultEmailTemplates` holds the shipped `text` and `html` of each email, so `generateOptionsForEmail` can tell a customized text apart.

#### Migration Steps
Please run the following command to update your project:

```bash
meteor update --release 3.7
```
